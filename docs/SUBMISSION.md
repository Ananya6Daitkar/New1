# LoopFit submission

## Project description
LoopFit helps communities exchange clothes they already own. Users list upper-body garments with measurements and condition photos, save pieces they want, and discover two- or three-person exchange loops. Matching considers each participant's configured size, style and garment chest preferences. Every participant approves independently, agrees to a public meeting location and confirms receipt after inspection.

The AI Studio integrates Perfect Corp's YouCam AI Clothes Try-On V3 server-to-server API. With permission, users submit a person photo and garment photo to generate an appearance preview, check the task and request deletion. This provides a visual aid before an exchange, not a guarantee of physical fit or condition.

Consumer value: a three-person exchange can work when no direct swap does. Event boundaries, explicit consent and owner-supplied condition evidence help people review an exchange before committing. A campus pilot is planned; no real-world adoption or environmental savings have been established.
